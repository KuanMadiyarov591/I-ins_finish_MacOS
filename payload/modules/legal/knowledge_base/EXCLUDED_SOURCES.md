# Реестр исключений

- Полная копия Закона № 4015-1 и повторные базовые стандарты не индексируются рядом с компактными проверенными версиями.
- Документы ВСС 2018–2019 годов не включены в активный корпус как исторические снимки.
- Сканированный внутренний стандарт с почти отсутствующим текстовым слоем исключён до OCR и ручной юридической проверки.
- ZIP-архивы и описательные файлы не индексируются.

Исходные материалы не удалены из общей базы знаний; исключение действует только для активного RAG юриста.
