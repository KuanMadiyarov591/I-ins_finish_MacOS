# PDF-база знаний юриста I-ins

В активном индексе 18 PDF: семь общих нормативных источников, семь специальных юридических источников и четыре внутренних регламента по PI, IMR, первичному приёму претензий и NDA.

Корпус содержит 715 страниц и 2185 чанков с обязательной привязкой к PDF и странице. Для явных процессов PI/IMR/NDA/intake используется маршрутизация к соответствующему внутреннему playbook; для нормативных вопросов поиск остаётся общим. При слабой релевантности ответ блокируется до обращения к LLM.

```powershell
python .\knowledge_base\rag_pipeline.py build
python .\knowledge_base\rag_pipeline.py validate
python .\scripts\test_vector_rag.py
```

ГПК и АПК очищаются от рекламных телефонов и адресов сайтов при извлечении. Все нормативные PDF являются версионными снимками: перед использованием в юридически значимом решении требуется проверка актуальной официальной редакции.
