# Нормативная база AI Hub

В каталоге находятся 35 актуарных нормативных документов и готовый поисковый индекс. Документы технической тематики и материалы других рабочих мест намеренно не включены.

## Состав

- `03_*.pdf` — исходные нормативные документы, которые можно открыть из ответа AI Hub;
- `rag_store/vectors.sqlite3` — готовый индекс: 35 документов и 2602 текстовых фрагмента;
- `rag_store/build_report.json` — показатели последней сборки;
- `rag_store/retrieval_qa.json` — результаты контрольных поисковых запросов;
- `rag_pipeline.py` — автономная сборка и проверка индекса.

Извлечённые тексты, `documents.jsonl` и `chunks.jsonl` не хранятся в GitHub, поскольку дублируют содержимое SQLite. При перестроении они будут созданы автоматически в `rag_store`.

## Перестроение индекса

Из корня Actuary Desk:

```powershell
.\.venv\Scripts\python.exe knowledge_base\rag_pipeline.py build
```

## Проверка

```powershell
.\.venv\Scripts\python.exe knowledge_base\rag_pipeline.py validate
```

Пример автономного поиска:

```powershell
.\.venv\Scripts\python.exe knowledge_base\rag_pipeline.py search "требования к актуарному заключению страховщика" --top-k 5
```

Индекс использует разреженные TF-IDF-признаки по словам, биграммам и символьным n-граммам. В приложении дополнительно действуют порог релевантности, расширение соседним контекстом и запрет запуска Qwen без подтверждённых материалов.
