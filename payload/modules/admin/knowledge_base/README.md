# Административная PDF-база знаний I-ins

Активный индекс содержит 16 PDF: семь общих страховых источников, требования Банка России, Правительства РФ и ФСТЭК, четыре стандарта по ИИ и инженерии знаний, а также два внутренних операционных чек-листа администратора.

Опубликованное Указание Банка России № 7219-У, вступающее в силу в 2027 году, сохранено отдельно в `reference_future` и намеренно не включено в рабочий индекс: будущие требования не должны смешиваться с действующими. Перед вводом в действие документ нужно повторно проверить и пересобрать индекс.

Админский кабинет использует отдельный процесс на порту 8003 и отдельный RAG-индекс, но обращается к рабочей SQLite-базе клиентского кабинета. Поэтому заявки и действия клиента видны администратору без копирования данных.

Проверки:

```powershell
python .\knowledge_base\rag_pipeline.py build
python .\knowledge_base\rag_pipeline.py validate
python .\scripts\test_vector_rag.py
python -m pytest -q
```
