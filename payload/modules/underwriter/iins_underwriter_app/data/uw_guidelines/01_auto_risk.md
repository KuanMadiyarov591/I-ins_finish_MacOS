# Автострахование — правила риска (Stage 1)

Краткий playbook для андеррайтера по линии **auto**.

## Красные флаги (decline / refer)

- **DUI ≥ 1** — усиленный контроль; при DUI ≥ 2 или DUI + несколько ДТП — склонность к **decline**.
- **Speeding violations ≥ 3** — повышенный риск; комбинировать с возрастом и пробегом.
- **Past accidents ≥ 2** — история убыточности; обычно **refer**.
- **Credit score < 0.35** — дополнительный фактор риска (не единственный).
- **Возраст 16–25** + малый стаж (0–9y) — молодой водитель, чаще **refer**.

## Зелёная зона (approve)

- Нет DUI, 0–1 нарушение, 0 ДТП.
- Credit score ≥ 0.5, пробег < 15 000.
- Возраст 26+, владение ТС, авто после 2015.

## Рекомендации по решению

| Риск-скор | Действие |
|-----------|----------|
| 0–44 | Approve (стандартные условия) |
| 45–74 | Refer (запрос документов / сюрвей) |
| 75–100 | Decline или жёсткие условия |

## Документы при refer

1. Водительское удостоверение и стаж.
2. История убытков / ГИБДД (если доступно).
3. Подтверждение владения и год выпуска ТС.
4. Пояснение по высокому пробегу (работа / такси).
