# Реестр исключений

- Полные или повторные версии Закона № 4015-1 и базовых стандартов Банка России не индексируются повторно: используются компактные проверенные копии из общего корпуса.
- Документы ВСС 2018–2019 годов оставлены как исторические материалы и не смешиваются с активными правилами.
- `underwriter_Внутренний стандарт по взаимодействию с получателями фин услуг.pdf` исключён из автоматической индексации: в PDF почти отсутствует извлекаемый текст, требуется OCR и ручная проверка.
- ZIP-архивы, методические описания и файлы без рабочего содержания не включаются в RAG.

Исключение означает отсутствие документа в активном поиске, но не удаление исходного файла из общей базы знаний.
