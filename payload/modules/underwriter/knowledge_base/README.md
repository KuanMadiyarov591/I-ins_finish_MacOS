# PDF-база знаний андеррайтера I-ins

В активном индексе 16 PDF: семь общих нормативных источников, пять специальных источников по ОСАГО и административной ответственности и четыре внутренних регламента андеррайтинга.

Поиск хранит имя PDF и страницу, возвращает только подтверждённые фрагменты и блокирует ответ при недостаточной релевантности. Для операционных вопросов о `approve / refer / decline`, fraud-сигналах и продлении приоритет отдан внутренним правилам. В интерфейсе источник открывается во всплывающем окне на нужной странице; над PDF показывается найденный фрагмент.

```powershell
python .\knowledge_base\rag_pipeline.py build
python .\knowledge_base\rag_pipeline.py validate
python .\scripts\test_vector_rag.py
```

Файлы, сознательно не включённые в индекс, перечислены в `EXCLUDED_SOURCES.md`. Нормативные PDF являются версионными снимками; перед производственным применением требуется контроль актуальности редакции.
