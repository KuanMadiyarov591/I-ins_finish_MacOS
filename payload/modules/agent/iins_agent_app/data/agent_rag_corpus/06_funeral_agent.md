# Похоронное страхование (funeral) — шпаргалка агента

## Кому предлагать
- Возраст 55+
- Клиенты, которые планируют заранее расходы на ритуальные услуги
- Семьи, где важна фиксированная выплата без долгого согласования

## Как говорить
Фокус на заботе о семье и предсказуемости расходов, без давления.
«Это покрытие помогает семье не решать финансовые вопросы в тяжёлый момент.»

## Чеклист продажи
1. Возраст и статус клиента
2. Бюджет премии
3. Бенефициар / контакт родственника (если уместно)
4. Согласие и документы
5. Draft → checklist → submit

## Не делать
- Не обещать суммы вне каталога
- Не смешивать с медскими гарантиями лечения
- Не использовать агрессивный closing
