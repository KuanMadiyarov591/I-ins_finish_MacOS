# PDF-база знаний страхового агента I-ins

В активном индексе 14 PDF: семь общих нормативных источников и семь внутренних рабочих документов агента — продуктовые условия, playbook, возражения, похоронное страхование и сценарии касаний.

Поиск сохраняет имя PDF и страницу, расширяет найденный фрагмент соседним контекстом и применяет порог релевантности. Если подтверждающего контекста нет, ответ блокируется до вызова Ollama. В интерфейсе каждый источник открывается в отдельном окне с выделенным найденным фрагментом.

```powershell
python .\knowledge_base\rag_pipeline.py build
python .\knowledge_base\rag_pipeline.py validate
python .\scripts\test_vector_rag.py
```
