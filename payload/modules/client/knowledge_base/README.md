# Клиентская PDF-база знаний I-ins

Корпус из 10 полнотекстовых PDF предназначен только для клиентского кабинета:

- 7 актуальных нормативных и регуляторных источников о договоре страхования, защите потребителя, финансовом уполномоченном и персональных данных;
- 3 внутренних документа с условиями демонстрационных продуктов I-ins.

`rag_pipeline.py build` извлекает текст по страницам, удаляет точные дубли фрагментов и создаёт переносимый SQLite-индекс `rag_store/vectors.sqlite3`. Команда `rag_pipeline.py validate` выполняет пять контрольных поисковых сценариев и сохраняет протокол в `rag_store/retrieval_qa.json`.

Интерфейс показывает только результаты, прошедшие порог релевантности. Каждая ссылка содержит имя PDF, номер страницы и найденный фрагмент; исходный документ открывается во всплывающем окне. Внутренние продуктовые документы являются справочным контекстом: при расхождении применяются подписанный договор и действующее законодательство.

Пересборка:

```powershell
python .\knowledge_base\rag_pipeline.py build
python .\knowledge_base\rag_pipeline.py validate
python .\scripts\test_vector_rag.py
```
