# I-ins 1.2.0 — установка на macOS

## Что нужно заранее

- Mac 2020 года или новее, Apple Silicon или Intel;
- 3 ГБ свободного места;
- интернет на время установки библиотек;
- Python 3.11, 3.12 или 3.13 с Tkinter — обычный установщик с
  [python.org/downloads/macos](https://www.python.org/downloads/macos/),
  вариант universal2. Python из Xcode Command Line Tools не подходит: в нём нет Tkinter.

## Установка

**1.** Склонируйте репозиторий (или распакуйте архив) в любую папку, кроме
Downloads — например, в «Документы»:

```bash
cd ~/Documents
git clone https://github.com/<владелец>/I-ins.git
cd I-ins
```

Git LFS не нужен: комплект лежит в репозитории распакованным, самый крупный
файл — 36 МБ.

**2.** Снимите карантин macOS и сделайте запуск исполняемым:

```bash
xattr -dr com.apple.quarantine .
chmod +x I-ins.command
```

**3.** Ключ GigaChat вводить заранее не нужно — установщик спросит его один
раз сам (шаг 4) и запомнит. Если хотите обойтись без вопроса, положите ключ
в файл рядом с программой до запуска:

```bash
echo 'sk-ваш-ключ' > gigachat.key
```

**4.** Проверьте, что всё на месте:

```bash
./I-ins.command --check-only
```

Первый прогон идёт 10–20 минут: собирается комплект из `payload/modules`,
создаётся окружение, ставятся библиотеки, распаковывается 262 МБ данных.
Посередине установщик один раз спросит ключ GigaChat: введите его (ввод скрыт)
или нажмите Enter, чтобы работать без GigaChat. Ключ проверяется на сервисе и
сохраняется в файле `gigachat.key` внутри папки данных — больше он не
спрашивается. Прогон должен закончиться строкой «Самопроверка пройдена».

**5.** Запустите:

```bash
./I-ins.command
```

Откроется окно со списком кабинетов. Кнопка «Открыть» рядом с кабинетом
запускает его в браузере. Закрытие окна останавливает все шесть.

## Выбор языковой модели

В каждом кабинете, в строке ввода вопроса, есть выпадающий список режимов:

- **Авто** — берёт локальный Qwen RAG, если он запущен; иначе GigaChat;
  иначе отвечает по базе знаний;
- **RAG по базе знаний** — ответ собирается только из найденных фрагментов PDF,
  без языковой модели, работает всегда;
- **Qwen RAG (локально)** — локальная модель Qwen через Ollama;
- **GigaChat (по API)** — облачная модель.

Недоступный режим показан в списке серым. Выбор запоминается в браузере.

В режимах Qwen RAG и GigaChat модель получает **только** те фрагменты базы
знаний, которые вернул поиск. Если поиск ничего не нашёл, модель не
вызывается — кабинет прямо отвечает, что основания в базе нет.

### Сменить или задать ключ GigaChat позже

```bash
echo 'sk-ваш-ключ' > ~/goinfre/I-ins/gigachat.key   # или в свою папку данных
./I-ins.command --check-only
```

В выводе появится строка `[ок] GigaChat: сервис отвечает`. Если написано
«ключ отклонён сервисом» — ключ неверный или просрочен; «нет связи» — сервис
недоступен с этой сети.

### Подключить локальный Qwen

```bash
brew install ollama
ollama serve &
ollama pull qwen2.5:1.5b
```

Перезапускать I-ins не нужно: кабинеты проверяют Ollama на каждом обновлении
состояния.

## Полная проверка всех шести кабинетов

```bash
./I-ins.command --smoke-test
```

Поднимает все шесть кабинетов на смещённых портах, проверяет вход, главную
страницу, полноту базы знаний, ответ поиска и наличие выбора модели. Отчёт: `logs/smoke-test.json` в папке данных.

## Отчёты актуария

Кабинет актуария → вкладка «Отчёты».

1. выберите вид отчёта: распределение премии, портфель, качество модели или
   тарифные факторы;
2. выберите модель для интерпретации: Qwen RAG, GigaChat или «по базе» —
   в последнем случае PDF выйдет без словесного разбора, с одними расчётами;
3. нажмите «Построить отчёт» — на экране появятся таблицы и текст модели,
   кнопка «Скачать PDF» отдаёт готовый документ.

Готовые отчёты остаются в подпапке `state/docs/actuary/reports` папки данных
и перечислены внизу вкладки.

## Если что-то пошло не так

| Что видно | Что делать |
|---|---|
| «Нужен Python 3.11–3.13 с Tkinter» | поставьте Python с python.org (universal2), не из Xcode |
| Файл не запускается двойным щелчком | `xattr -dr com.apple.quarantine .` и `chmod +x I-ins.command` |
| «Порт 8000 занят другой программой» | `IINS_PORT_OFFSET=12000 ./I-ins.command` |
| Установка библиотек падает | проверьте интернет и прокси; журнал: `bootstrap.log` в папке данных |
| Версия scikit-learn отличается | это допустимо: самопроверка реально грузит все 20 моделей и скажет, работают ли они |
| Режим GigaChat серый | ключа нет: `./I-ins.command --gigachat-test` покажет, где именно рвётся |
| GigaChat выбирается, но отвечает ошибкой | `./I-ins.command --gigachat-test` — печатает HTTP-код и ответ сервиса |
| `certificate verify failed` | у Python с python.org нет корневых сертификатов; `python3 gigachat_check.py` покажет, помогает ли набор certifi, а `I-ins.command` подставляет его сам |
| Сеть требует прокси | `export HTTPS_PROXY=http://proxy:3128` перед запуском `./I-ins.command` |
| Режим Qwen RAG серый | не запущена Ollama или не скачана модель `qwen2.5:1.5b` |
| Отчёт не строится, «нужна библиотека reportlab» | запустите `./I-ins.command` заново — библиотека доустановится |
| Нужно переустановить начисто | удалите папку данных (см. «Где что лежит») и запустите заново |

## Где что лежит

| | |
|---|---|
| Программа | папка, куда вы её склонировали или распаковали |
| Данные, базы, журналы | `~/goinfre/I-ins` на учебных Mac, иначе `~/Library/Application Support/I-ins` |
| Окружение Python | подпапка `venv-1.2.0-macos` там же |
| Отчёты актуария | подпапка `state/docs/actuary/reports` там же |

Установщик печатает выбранный путь и объём свободного места перед началом.
Поставить в другое место: `IINS_HOME=/Volumes/Data/I-ins ./I-ins.command`.

На учебных Mac `~/goinfre` периодически очищается. После очистки просто
запустите `./I-ins.command` снова — окружение и комплект восстановятся, ключ
GigaChat спросится один раз.

Удаление: удалите папку программы и папку данных из таблицы выше.

## Если правили исходный код

Исходники шести кабинетов лежат в `payload/modules` и работают оттуда же.
Правки вступают в силу при следующем запуске `./I-ins.command` — пересобирать
ничего не нужно.
